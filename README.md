# AI Research Copilot

AI-powered PDF Research Assistant built using LangChain, Streamlit, FAISS, and Groq LLMs.

## Live Demo

[Open App](https://ai-research-copilot-gcargjccwkzuttbuztqmda.streamlit.app/)

## Features

- PDF Upload
- AI Summarization
- AI Question Answering
- Quiz Generation
- RAG-based Retrieval
- LLM Integration

## Tech Stack

- Python
- Streamlit
- LangChain
- FAISS
- Groq API
- Llama 3.1
- Sentence Transformers

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
