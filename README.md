# AI Research Copilot

AI-powered PDF Research Assistant built using LangChain, Streamlit, FAISS, and Groq LLMs.

## Features
- PDF Upload
- AI Summarization
- Question Answering
- Quiz Generation
- RAG-based Retrieval

## Tech Stack
- Python
- Streamlit
- LangChain
- FAISS
- Groq API
- Llama 3.1

## Run Locally

pip install -r requirements.txt

streamlit run app.py
